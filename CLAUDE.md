# CLAUDE.md

Groundwork, a starter-home land search for Orange County. The product spec is `site/PRODUCT_SPECS.MD`.

- **`site/`:** the Next.js app, including the Prisma schema for every table. See `site/CLAUDE.md`.
- **`pipeline/`:** the offline Python data jobs that fill the parcel and zone tables. See `pipeline/CLAUDE.md`.

Both use the same Neon database.
